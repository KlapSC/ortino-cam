# Tastenkürzel

Diese Seite listet die Tastenkürzel von ortino.CAM unter Windows. Im Programm zeigt dir die Taste `?` (also `Umschalt+ß` auf einer deutschen Tastatur) oder Hilfe → »Tastenkürzel anzeigen« die aktuelle Liste. Die Befehlspalette (`Strg+K`) findet **jeden** Befehl per Stichwort und zeigt sein Kürzel an. Einzelne Kürzel wirken nur im passenden Schritt, solange du nicht in einem Textfeld tippst.

> Die Belegung ist fest. Frei belegbare Kürzel gibt es in dieser Version nicht.

## Überall

| Kürzel | Wirkung |
|---|---|
| `Strg+K` | Befehlspalette |
| `?` | Tastenkürzel anzeigen |
| `Alt+1` bis `Alt+5` | zum Schritt Projekt, Design, Bearbeitung, Prüfen, Fräsen |
| `Strg+N` | Neues Projekt |
| `Strg+O` | Projekt öffnen |
| `Strg+S` | Speichern |
| `Strg+Umschalt+S` | Speichern unter |
| `Strg+I` | Datei importieren (SVG, DXF, PDF/AI, Bild) |
| `Strg+Z` | Rückgängig |
| `Strg+Y` oder `Strg+Umschalt+Z` | Wiederholen |
| `Strg+B` | Seitenleiste ein- und ausblenden |
| `Strg+J` | Eigenschaften-Panel ein- und ausblenden |
| `Strg+Umschalt+D` | Community-Portal öffnen |
| `Strg+Umschalt+M` | Möbel und Küche |
| `Strg+L` | Assistent öffnen |
| `Strg+Umschalt+L` | »Frag Claude zu dieser Ansicht« |

## Design: Werkzeuge

| Taste | Werkzeug |
|---|---|
| `V` | Auswählen |
| `A` | Knoten bearbeiten |
| `R` | Rechteck |
| `E` | Ellipse und Kreis |
| `P` | Vieleck (`S` schaltet zum Stern um, Ziffern 3 bis 32 oder `↑`/`↓` stellen die Eckenzahl ein) |
| `L` | Linie und Polylinie |
| `B` | Stift (Bézier-Kurven) |
| `Umschalt+B` | Freihand |
| `T` | Text |
| `M` | Messen |
| `O` | Ecken verrunden |
| `H` | Fase |
| `X` | Kürzen |
| `N` | Verlängern |
| `Esc` | Eingabe abbrechen, dann zum Auswählen wechseln, dann Auswahl aufheben |

## Design: Bearbeiten und Ansicht

| Kürzel | Wirkung |
|---|---|
| `Strg+A` | alles auswählen |
| `Strg+C`, `Strg+V` | kopieren, einfügen |
| `Strg+D` | duplizieren |
| `Entf` | löschen |
| `Umschalt+H`, `Umschalt+V` | horizontal, vertikal spiegeln |
| Pfeiltasten | Auswahl um einen Rasterschritt verschieben (mit `Umschalt` zehnfach) |
| `F` oder `Pos1` | Ansicht einpassen |
| `Z` | auf die Auswahl zoomen |
| Mausrad | zoomen |
| mittlere Maustaste ziehen oder `Leertaste` halten und ziehen | Ansicht verschieben |

## Knoten, Stift und Freihand

| Kürzel | Wirkung |
|---|---|
| `Tab`, `Umschalt+Tab` | nächster, vorheriger Knoten |
| `Einfg` oder `+` | Knoten in der Mitte der gewählten Segmente einfügen |
| `Entf` | Knoten löschen, die Form möglichst erhalten |
| `Strg+Entf` | Knoten löschen ohne Formerhalt |
| `Umschalt+C`, `Umschalt+S`, `Umschalt+Y` | Knotentyp: Ecke, glatt, symmetrisch |
| `Umschalt+L`, `Umschalt+A`, `Umschalt+U` | Segmenttyp: Linie, Bogen, Kurve |
| `Umschalt+J` | Endknoten verbinden, offenen Pfad schließen |
| `Umschalt+X` | an gewählten Knoten trennen |
| `Umschalt+R` | Richtung umkehren |
| `Umschalt+T` | Einstichstelle setzen (der Fräsweg beginnt dort) |
| Pfeiltasten | gewählte Knoten verschieben (mit `Umschalt` zehnfach, mit `Alt` ein Zehntel) |
| Stift: `Rücktaste` | letzten Knoten zurücknehmen |
| Stift: `Enter`, Doppelklick oder `Esc` | Linie beenden |
| Stift: `Umschalt` beim Ziehen | Winkel in 15°-Schritten einrasten |

## Prüfen und Fräsen

| Kürzel | Wirkung |
|---|---|
| `Leertaste` (im Schritt Prüfen) | Simulation abspielen oder pausieren |
| Pfeiltasten (Karte »Handsteuerung«, bei eingeschaltetem Schalter »Tastatur« oder wenn der Fokus in der Karte steht) | X und Y verfahren |
| `Bild↑`, `Bild↓` | Z verfahren |
| `Umschalt` | zehnfache Schrittweite |

> Im Schritt Fräsen bewegen diese Tasten die **echte Maschine**. Schalte den Schalter »Tastatur« nur ein, wenn du ihn brauchst, und halte den Not-Aus in Reichweite.

## In Dialogen und Studios

| Kürzel | Wirkung |
|---|---|
| `Strg+Enter` | einfügen oder übernehmen (Bild nachzeichnen, Muster-Studio, Relief-Studio, Passungs-Assistent, Verbindungen, Vorlagenformular) |
| `Esc` | Dialog schließen oder Eingabe verwerfen (bei ungespeicherten Eingaben fragt das Programm nach) |
| Pfeiltasten im Muster-Studio | Vorlagenkarte wechseln |
| `+`, `-`, `0` im Muster-Studio | zoomen, auf Platte einpassen |

## Möbel und Küche

| Kürzel | Wirkung |
|---|---|
| `O` | Türen öffnen und schließen |
| `E` | Explosionsansicht |
| `M` | Maße anzeigen |
| `B` | Bohrungen anzeigen |
| `C` | Teile nach Schrank einfärben |
| `G` | Material und Platten der Küche |
| `K` | Küche (einheitliche Einstellungen) |
| `N` | neuer Unterschrank |
| `2`, `3` | Stückliste, Zuschnitt |
| `↑`, `↓` | Schrank wählen |
| `Alt+←`, `Alt+→` | Schrank verschieben |
| `Entf` | löschen |
| `Strg+D` | duplizieren |
| `Esc` | schließen |
