# Maschinenprofile

Hier sammeln wir Maschinenprofile, die jemand an einer echten Maschine benutzt hat.

**So trägst du eines bei:** In ortino.CAM »Maschinen« → Profil → **Exportieren**. Die Datei ohne Höhenkarte und ohne persönliche Notizen als Pull Request hier ablegen, Dateiname `hersteller-modell-steuerung.json` (zum Beispiel `ultimate-bee-1000-xpro-v5.json`). Im Pull Request die Quelle der Maße nennen und ob du die Maschine selbst benutzt.
